# 이직 준비 노트

공고를 분석하고, 그 공고에 맞춰 이력서와 포트폴리오를 다듬는 무료 도구예요.
회원가입이나 설치 없이 브라우저에서 바로 써요.

## 할 수 있는 것

| 메뉴 | 하는 일 |
|---|---|
| **① 나 (기준·역량)** | 내 역량, 업무 숙련도, 강점·약점, 회사를 고르는 기준을 Q&A로 정리해요. |
| **② 공고·직무·회사 분석** | 잡플래닛·원티드·회사 홈페이지 공고를 넣으면 JD 분석, 나와 맞는 정도(적합도), 산업·브랜드 분석, 그 직무에서 내 강점·보완점과 피드백을 정리해요. |
| **③ 이력서 피드백** | ②에서 분석한 회사 1곳을 고르고 이력서를 넣으면, 그 회사에 맞춰 고칠 문장을 "원래 → 고친 문장"으로 알려 줘요. |
| **④ 포트폴리오 피드백** | ②에서 분석한 회사 1곳을 고르고 포트폴리오(PDF·이미지)를 넣으면, 그 회사 기준으로 피드백을 줘요. |

②에 있는 **나와 맞는 회사 찾기**는 잡플래닛 검색 결과를 붙여넣으면 ①의 기준으로 잘 맞는 곳을 골라 줘요.

### 공고 넣는 방법

공고 링크를 넣고 **열기**를 누르면 새 탭에 공고가 떠요. 그 탭에서 **Ctrl+A → Ctrl+C** 한 뒤 붙여넣고 **AI로 항목 정리**를 눌러요. 저장하면 JD·회사 분석은 자동으로 돼요.

## 처음 시작하기

1. 페이지를 열고 오른쪽 위 **설정·백업**을 눌러요.
2. **Gemini API 키**(무료)를 넣어요.
   1. https://aistudio.google.com/apikey 에 구글 계정으로 로그인해요.
   2. **API 키 만들기(Create API key)**를 눌러 키를 복사해요.
   3. 키 칸에 붙여넣고 **저장** → **연결 확인**을 눌러요.
3. **① 나**부터 채우고, **②**에 관심 있는 공고를 넣어 보세요.

## 내 정보는 어디에 저장되나요?

- 이력서, 공고, 분석 결과, API 키는 **지금 쓰는 브라우저 안에만** 저장돼요. 이 사이트를 만든 사람을 포함해 누구에게도 전송되지 않아요.
- AI 분석을 누를 때만 그 내용이 **내 API 키로 Google Gemini**에 보내져요.
- 무료 Gemini 키는 Google이 입력 내용을 서비스 개선에 쓸 수 있어요. 주민번호·연락처 같은 민감한 정보는 넣지 마세요.

## 꼭 알아 둘 것

- 브라우저 기록·사이트 데이터를 지우면 내용이 사라져요. **설정·백업 → 백업 파일 받기**로 가끔 백업해 두세요.
- 다른 컴퓨터에서 이어 쓰려면 그 백업 파일을 **백업 불러오기**로 넣으면 돼요.
- 시크릿(InPrivate) 창에서는 창을 닫으면 내용이 지워져요.
- 무료 한도 때문에 연달아 누르면 "요청이 많아요"가 뜰 수 있어요. 잠깐 뒤 다시 눌러 주세요.
- AI 분석 결과는 참고용이에요. 중요한 내용은 공고 원문에서 다시 확인하세요.

## 이용 조건

무료로 자유롭게 쓰고 공유할 수 있어요. 결과에 대한 책임은 사용자에게 있어요.
