이직 준비 노트

공고를 분석하고, 그 공고에 맞춰 이력서와 포트폴리오를 다듬어요. 데이터는 지금 쓰는 브라우저에만 저장돼요.

AI 분석을 쓰려면 무료 Gemini API 키가 필요해요.

이력서 추가

PDF 올리기 PDF에서 글자를 뽑아 아래 칸에 채워요. 이미지로만 된 PDF는 글자를 못 읽으니 직접 붙여넣어 주세요.

포트폴리오 추가

PDF 또는 이미지 올리기 PDF는 쪽마다 이미지로 바꿔 저장해요 (최대 30쪽). AI가 디자인과 내용을 같이 봐요.

설정·백업

AI (Google Gemini, 무료)
  1. aistudio.google.com/apikey 에 개인 구글 계정으로 로그인해요.
  2. ‘API 키 만들기(Create API key)’를 눌러 키를 복사해요.
  3. 아래 칸에 붙여넣고 저장해요. 키는 지금 쓰는 브라우저에만 저장돼요.
백업 데이터는 이 브라우저에만 있어요. 브라우저 기록·사이트 데이터를 지우면 사라지니 가끔 백업 파일을 받아 두세요. 다른 컴퓨터로 옮길 때도 이 파일을 써요.

공고 추가

1. 공고 링크로 불러오기 잡플래닛·원티드·사람인·잡코리아·링크드인·회사 채용 페이지 등 어떤 링크든 돼요. ‘열기’를 누르면 새 탭에 공고가 열려요. 그 탭에서 Ctrl+A → Ctrl+C 한 뒤 아래 2번 칸에 붙여넣어 주세요. 저장하면 JD·회사 분석까지 자동으로 해요.
2. 또는 공고 내용 붙여넣기
회사명·포지션·마감일·본문을 나눠 채워요.
